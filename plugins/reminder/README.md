# 群聊定时提醒插件 (reminder)

在已授权启用的微信群聊中，为群成员提供单次定时提醒能力。支持自然语言 `@机器人` 或斜杠命令创建、查看与取消提醒，到点由框架调度器自动发送带真实群艾特（`@成员`）的通知。

> **说明**：本插件默认 100% 走本地确定性规则解析，不依赖大模型 API，未配置模型时也可独立完整运行。数据隔离存储在 `.runtime/reminders.sqlite3`，不修改或写入任何私有 JSON 配置文件。

## 一、命令入口

### 1. 创建提醒
- **入口 A（群内真实 @ 机器人）**：
  - `@机器人 10分钟后提醒我关火`
  - `@机器人 提醒我明天上午9点半参加晨会`
  - `@机器人 今晚20:30提醒我提交周报`
- **入口 B（群内确定性斜杠命令）**：
  - `/提醒 15:00 喝水休息`
  - `/提醒 10分钟后 喝水`
  - `/提醒 明天09:30 开会`

### 2. 查看提醒
仅返回发送者本人在当前群的待触发提醒（按时间升序）：
- `@机器人 我的提醒`（同义：`查看提醒`、`提醒列表`）
- `/我的提醒`（同义：`/提醒列表`）

### 3. 取消单条提醒
- `@机器人 取消提醒 1`
- `/取消提醒 1`

### 4. 取消全部提醒
取消本人在当前群的所有待触发提醒：
- `@机器人 取消全部提醒`（或 `@机器人 取消提醒 全部`）
- `/取消全部提醒`（或 `/取消提醒 全部`）

## 二、支持的时间表达
1. **相对时间**：
   - `N分钟后`、`十分钟后`、`半小时后`、`N小时后`、`N小时M分钟后`、`一个半小时后`、`N天后`（保留当前时分）。
2. **当天时刻**：
   - 24 小时制 `HH:MM`（如 `15:00`、`20:30`）。
   - `HH点MM分`、`HH点MM`、`HH点半`、`HH点`。
   - 搭配时段词：`早上/上午/中午/下午/傍晚/晚上/今晚/凌晨`（如 `下午3点` → `15:00`，`今晚8点半` → `20:30`）。
3. **跨天日期 + 时刻**：
   - `明天/明日`、`后天`、`大后天` + 具体时刻（如 `明天09:30`、`后天下午2点`）。
   - `M月D日 HH:MM`（如 `10月25日 09:30`）。
   - `YYYY-MM-DD HH:MM`（如 `2026-10-25 15:00`）。

## 三、限制与隔离规则
1. **单次提醒**：首期仅支持单次提醒，命中 `每天`、`每周` 等周期词时直接拒绝。
2. **仅日期无时刻拦截**：如 `@机器人 明天提醒我交周报`，提示补充具体时刻。
3. **已过时刻不顺延**：若指定时刻已过去，明确提示失败，不自动顺延至次日。
4. **时间范围**：最短 1 分钟后（< 60 秒拒绝），最长未来 30 天内。
5. **事项字数**：单行纯文本，1–100 个字符。
6. **仅支持为自己设置**：禁止替其他群成员设置，若消息艾特他人或含 `提醒他人/大家` 等句式一律拒绝。
7. **容量上限**：每人每群最多 5 条待触发提醒，每群总计最多 30 条待触发提醒。
8. **三级隔离**：按 `(account, room, creator)` 隔离，群之间、成员之间、机器人账号之间互不可见、互不影响。
